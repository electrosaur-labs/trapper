# Assistant Notes & Common Patterns

This file tracks observations about assistant behavior, common mistakes, and preferences to help provide better context in future conversations.

## Common Mistakes to Watch For

### 1. Verification Logic Issues (Session: Jan 2, 2026)
- **Mistake**: Initially tried to reverse layer flattening order (darkest to lightest) which made verification worse
- **Root cause**: Didn't fully understand that verification logic was the issue, not the flattening order
- **Correct approach**: Fixed the verification to accept valid trapping overlaps (lighter over darker) instead of expecting exact pixel matches
- **Lesson**: When tests fail, investigate the test logic itself before changing the implementation

### 2. File Operations
- **Pattern**: Sometimes attempts to copy large files (47MB PSDs) to source control without considering size
- **Preference**: Always check file sizes before adding to git; use test fixtures or resized versions instead
- **Solution**: Created PsdResizer utility to generate smaller test files

### 3. Test Design
- **Pattern**: Initially created overly strict tests (expected trapped pixels > 0)
- **Lesson**: Tests should focus on what matters (no invalid changes) rather than implementation details

## Project-Specific Preferences

### Trapping Verification
- Lighter colors trapping over darker colors is **expected behavior** in offset lithography
- Only flag as errors when darker colors replace lighter colors
- Always verify understanding of trapping principles before modifying verification logic

### Source Control
- Exclude `.claude/` directory (local settings)
- Keep test PSDs small (<1MB preferred)
- Always check file sizes before git add

### Testing Approach
- Use golden reference files for regression testing
- Byte-for-byte comparison for exact output matching
- Pixel-by-pixel comparison with tolerance for flattened verification

## Useful Context for Future Sessions

### Project Structure
```
src/main/java/org/electrosaur/trapper/
  - PsdColorSeparator.java (main trapping engine)
  - PsdResizer.java (utility for creating test fixtures)
  - TrappingStrategy.java (interface for offset/screen modes)
  - TrapperGUI.java (Swing interface)

src/test/java/org/electrosaur/trapper/
  - TrappingVerificationTest.java (integration tests)
  - PsdColorSeparatorTest.java (unit tests)

src/test/resources/
  - test-complex.psd (input test file)
  - test-complex-trapped.psd (golden reference)
```

### Key Commands
```bash
# Run trapping with default settings
./gradlew runColorSeparator --args="input.psd"

# Resize PSD for test fixtures
./gradlew resizePsd -PpsdFile=input.psd -Pscale=0.1

# Run verification tests
./gradlew test --tests TrappingVerificationTest

# Launch GUI
./gradlew runGUI
```
